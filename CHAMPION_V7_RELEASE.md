# Экспериментальная сборка v7 — 25.10.2026

Архив: outputs/automl_champion_v7_anchors_ensemble_20261025.zip.
Контроль 2157.225 не изменён и не заменён этой сборкой.

## Что изменилось

1. Для site_eui / Year_Factor добавлен run_regression_anchors: два встроенных
   рецепта CatBoost/LightGBM, три временных варианта истории и их фиксированный
   ансамбль заново измеряются на текущих данных. Прошлые 39.9274 mean RMSE —
   происхождение рецепта, а не результат новой версии. При частичном завершении
   сохраняются уже готовые кандидаты.
2. Temporal-ансамбли поддерживают 2–4 одиночных suite с явным member_modes.
   Сырой FLAML можно проверить в смеси даже при проигрыше отдельно. Его точный
   компонент экспортируется отдельно, без замены выбранного режима источника.
   Вложенные ансамбли и повторный учёт reference как новой модели запрещены.
3. Для AutoGluon-классификации добавлен audit_classification_shift: сравнение
   сохранённых OOF-вероятностей на полном OOF и test-like срезе из adversarial
   validation. Это условная диагностика уже использованной проверки; она
   не является независимым тестом, не обучает веса и не выбирает победителя.
4. Новые инструменты, память, исследовательский план и итоговый аудит соединены
   с контроллером Qwen. Все необходимые рецепты встроены в Python.

## Фактические платформенные настройки

- Общий бюджет 9900 секунд, 8 CPU-потоков; одно обучение одновременно.
- Один исследователь, reviewer включён, analyst отключён; максимум 60 шагов.
- Регрессия: AutoGluon 0, FLAML 1800 секунд суммарно на поиск и fold refit.
- Классификация: AutoGluon 3600 секунд суммарно, FLAML 0.
- Лимит одного шага 3600 секунд; общий дедлайн сохраняет приоритет.
- Явные --flaml-budget 0 и --autogluon-budget 0 отключают соответствующий поиск.

## Состав и статус

Только корневые .py и requirements.txt. Нет данных, ключей, истории или готовых
обученных моделей. JSON-состояние создаётся во время работы; внешние JSON для
старта не нужны. Платформа запускает поиск и обучение заново.

По просьбе пользователя для этой сборки не запускались тесты, Qwen, обучения
и проверка платформы. При упаковке выполняется только статическая компиляция
Python и контроль состава/целостности ZIP. Нового измерения качества нет.
Загрузку на платформу выполняет пользователь.

## LightAutoML — следующий отдельный эксперимент

В этом релизе новый backend LightAutoML не добавлен. Его можно подключить как
ещё один ограниченный по времени кандидат: линейная модель и бустинги, сравнение
на тех же внешних фолдах, подбор только внутри train-части. Затем проверить
фиксированную смесь с текущим победителем и отдельно реализовать экспорт.
Для классификации сохранять вероятности и настраивать правило Macro F1 только
во внутренней калибровке. Бюджет 1200–1800 секунд нужно делить между всеми fit,
а не выделять каждому фолду заново. Прирост заранее не гарантирован.
