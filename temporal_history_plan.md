Работаем с отдельным временным сравнением, а не с прежним single-holdout рейтингом.

1. Прочитай temporal_comparison из памяти. Если отчёта нет или среди результатов нет history_gate, вызови run_temporal_suite:
   base_experiment_id=213, time_column="Year_Factor",
   key_columns=["State_Factor","facility_type","building_class","floor_area","year_built","ELEVATION"],
   group_columns=["State_Factor","building_class","facility_type"], validation_periods=[3,4,5], history_gate=true.
   Вызывай только если этот рецепт существует и задача соответствует данным.
2. Инструмент проверяет baseline, history_exact, history_groups и history_gate.
   history_gate использует history_exact только при наличии прошлого по полному
   точному ключу, иначе baseline. Правило фиксировано, пороги по таргету не подбираются.
   Оно предложено после предыдущего анализа: эти годы уже не независимый тест.
   Гиперпараметры одинаковые, число деревьев выбирается внутренней временной
   проверкой отдельно в каждом варианте и внешнем фолде. Не сравнивай новый
   mean_rmse с прежним RMSE на году 5 как одну метрику.
3. Анализируй mean_rmse, latest_rmse, worst_rmse, изменения каждого фолда,
   покрытие ключа и segments (seen_key/unseen_key). Прочитай полный report.json
   через run_python при необходимости. Рецепт уже выбран на старой валидации,
   поэтому это не полностью независимая оценка и не доказательство потолка качества.
4. Ключ описывает совпадение характеристик, не подтверждённую личность здания.
   Не объединяй ключи массовым округлением площади без проверки неоднозначности.
5. finalize_temporal сохраняет отдельный модельный пакет и submission.csv внутри
   temporal/<suite_id>. Для публикации временного результата явно вызови
   select_final_candidate(kind="temporal", suite_id=<выбранный suite>).
   Тогда основной финализатор опубликует выбранный временной pipeline. Старый
   single-holdout best в истории сохранится. Не переписывай submission вручную.
6. Не подбирай десятки вариантов ключей/весов на тех же годах. Сначала объясни,
   где история действительно помогла, а где ухудшила. Пиши по-русски.
