# Продолжение исследования

Цель — улучшать AutoML-агента с помощью измеренных экспериментов, сохраняя лучший результат.

1. Прочитай память и secondary_checks. Основной RMSE регрессии: ансамбль №150 = 39.682126.
   Он сохранён отдельным снимком. Не заменяй его вариантом с худшей основной метрикой.
2. Используй inspect_categories для State_Factor, building_class, facility_type.
   Усечение семи байтов теряет категории, а перебор модулей подгоняет числовой порядок.
   Прочитай полные рецепты №131 и №135 через read_experiment.
3. Уже выполненная проверка фиксированных рецептов:
   - годы 1–3 → 4: прежний ансамбль №79 = 44.4001, №150 = 44.1915;
   - замена хэша полными строками с прежними числом деревьев и весами: 43.5155 на году 4,
     но 47.7194 на году 5. Это НЕ новый победитель.
   Простая замена не подтверждена. Нужен отдельный выбор числа деревьев и регуляризации
   нативной категориальной модели через train_model с early stopping на основной валидации.
4. Сравни ограниченное число разных гипотез: строковые категории с регуляризацией,
   наличие/отсутствие временного признака, разумные взаимодействия площади и назначения
   здания. Меняй один существенный фактор за раз. Не перебирай новые хэш-модули.
5. Выбери 2–3 сильных новых кандидата по основной метрике. Проверь их через
   validate_experiment на Year_Factor=4. Не смешивай оценки разных периодов и не называй
   эту проверку независимым тестом: ранние периоды уже исследовались.
6. Делай ансамбли из действительно разных моделей; не трать весь бюджет на мелкий
   подбор весов. Остановись при отсутствии новых обоснованных гипотез.
7. В финальном отчёте укажи основную метрику, вторичную проверку, ограничения и
   оставшиеся гипотезы. Финальное переобучение и выбор победителя выполняет контроллер.

Это план регрессии. Для классификации требуется отдельный запуск и собственная история.
